How it works

This page uses the browser Web Audio API instead of uploading audio. It samples the microphone, computes a frequency spectrum with an analyser node, estimates loudness with RMS energy, finds the strongest frequency bin, and compares current energy against a rolling baseline. The score is a heuristic confidence for sudden audio spikes, so it is useful for monitoring sound changes but is not a trained speech or music classifier.
